# الإتحادية للنقل العمومي — الحالة والتشغيل

## الإعداد
1. أنشئ مشروع Supabase، ثم شغّل بالترتيب من SQL Editor: `0001_schema.sql` ← `0002_booking_logic.sql` ← `0003_rls.sql` ← `0004_public_reads.sql` ← `0005_auth_agency.sql` ← `0006_rate_limits.sql` ← `0007_directory_admin.sql`.
2. للتجربة فقط: `seed_demo.sql` (كل سجلاته موسومة `is_demo = true`).
3. انسخ `.env.example` إلى `.env.local` واملأ القيم. لا ترفع المفاتيح السرية إلى Git.
4. في Supabase: Authentication ← Providers ← Email (أبقِ تأكيد البريد مفعّلًا أو عطّله للتجربة). ثم لإنشاء مسؤول: سجّل حسابًا ثم نفّذ من SQL Editor فقط: `update profiles set role='admin' where id='<uuid>';`
5. فعّل `pg_cron` وجدول `expire_holds()` (السطر الأخير في 0002).
6. `npm install && npm run dev` — للنشر: Vercel مع نفس متغيرات البيئة.

## ما أُنجز (لم يُختبر ضد قاعدة حقيقية بعد)
- المخطط، حالات الانتقال، RLS، حجز بقفل صفوف وقيد تفرد للمقاعد، انتهاء المهلة، تأكيد/رفض/إلغاء، تسجيل الدفع النقدي، تتبع الضيف، سجل الأحداث.
- الصفحات: الرئيسية، البحث `/search`، تفاصيل الرحلة والحجز `/trip/[id]`، التتبع `/track` ، الدخول `/login`، لوحة الوكالة `/agency` (رحلات، حجوزات، تأكيد/رفض، دفع نقدي، تصدير CSV)، لوحة الإدارة `/admin` (اعتماد الوكالات). كلها مكتوبة ولم تُشغَّل بعد.

- دليل الوكالات `/agencies` مع بحث بالاسم أو المدينة وروابط مباشرة لرحلاتها.
- لوحة الإدارة: اعتماد الوكالات، العمولة لكل وكالة وتقرير المستحق، إضافة المدن والمسارات، آخر الحجوزات، وسجل عمليات الإدارة.

## النشر على Vercel
1. ارفع المجلد إلى GitHub (مستودع خاص). 2. في vercel.com: Add New ← Project ← اختر المستودع. 3. في Environment Variables أضف المتغيرات الثلاثة من `.env.example` (بدون service_role). 4. Deploy. 5. في Supabase: Authentication ← URL Configuration: ضع رابط Vercel في Site URL.

## الاختبارات
- `supabase/tests/booking_tests.sql`: 5 اختبارات (مقعد مكرر، السعة، انتهاء المهلة، حد التتبع، حد الحجوزات لكل هاتف) تُشغَّل في SQL Editor وتنتهي بـ ROLLBACK.
- `tests/concurrency.mjs`: 15 طلبًا متوازيًا على المقعد نفسه، يجب أن ينجح واحد فقط.
- `supabase/tests/README.md`: قائمة فحص الصلاحيات اليدوية.
- الاختبارات لم تُشغَّل بعد في بيئة حقيقية.

## المتبقي (لم يُنفّذ)
- الصفحات القانونية موجودة كمسودة تحتاج مراجعة قانونية، وبيانات التواصل تُضبط من `.env`.
- إدارة الشكاوى وإعدادات سياسات المنصة من لوحة الإدارة (غير مبنية).
- تعديل رحلة قائمة، وإحصاء المقاعد المتاحة في لوحة الوكالة. الروابط والنموذج في الرئيسية تشير إليها وستعمل عند بنائها.
- جدول `trip_seats` استُبدل بـ `booking_seats` مع فهرس فريد جزئي. جدول `notifications` مؤجل.
- الدفع الإلكتروني (طبقة المزود): لم يُكتب بعد، ويظهر «غير متاح حاليًا». حد الطلبات مطبّق على التتبع والحجز فقط، ولا حماية على مستوى الشبكة (يُنصح بتفعيل حماية Vercel).
