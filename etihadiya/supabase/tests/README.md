# قائمة اختبارات الصلاحيات (يدوية، بحسابات منفصلة)
1. سجّل حسابين وكالة (أ) و(ب) واعتمدهما من لوحة الإدارة، وأنشئ حجزًا لكل وكالة.
2. من وكالة (أ): تأكد أن /agency لا يعرض أي حجز لوكالة (ب)، وأن تصدير CSV لرحلة (ب) يعيد ملفًا فارغًا.
3. من حساب مسافر عادي: افتح /admin ويجب أن يُعاد توجيهك للرئيسية.
4. من SQL (بحساب مسافر عبر `set local role authenticated`): `update profiles set role='admin'` يجب أن يفشل (صلاحية العمود محجوبة).
5. وكالة غير معتمدة: لا تظهر رحلاتها في البحث ولا يمكنها إنشاء رحلات.
6. افحص سجلات Vercel/Supabase: لا أرقام هواتف ولا مفاتيح.
